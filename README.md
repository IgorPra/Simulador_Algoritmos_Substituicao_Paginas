# Simulador de Algoritmos de Substituicao de Paginas

## Objetivo

Este projeto e um simulador Java para comparar algoritmos de substituicao de paginas em memoria. A partir de uma sequencia de paginas e de uma quantidade de quadros, o simulador calcula a quantidade de faltas de pagina geradas por cada algoritmo.

## Algoritmos implementados

- FIFO
- LRU
- Relogio
- Otimo

## Como compilar

```bash
javac *.java
```

## Como executar

```bash
java Main
```

## Como usar

1. Selecionar um modelo de execucao ou digitar os valores.
2. Informar a sequencia de paginas.
3. Informar a quantidade de quadros.
4. Clicar em "Simular".

## Saida

A saida mostra a quantidade de faltas de pagina de cada algoritmo, permitindo comparar o desempenho entre FIFO, LRU, Relogio e Otimo.
